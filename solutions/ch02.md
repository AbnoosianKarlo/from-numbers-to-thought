## Programming exercises

**2.25** Implement the Gaussian elimination algorithm to convert an augmented matrix into reduced row-echelon form and test it on the system of Example 2.6. Compare the result with the output of np.linalg.matrix_rank.

```python
import numpy as np
 
def rref(M, tol=1e-12):
    A = M.astype(float).copy()
    rows, cols = A.shape
    r = 0                                  # current pivot row
    for c in range(cols):
        p = r + np.argmax(np.abs(A[r:, c]))  # partial pivoting
        if abs(A[p, c]) < tol: continue
        A[[r, p]] = A[[p, r]]              # swap rows
        A[r] /= A[r, c]                    # scale pivot to 1
        for i in range(rows):
            if i != r: A[i] -= A[i, c] * A[r]
        r += 1
        if r == rows: break
    return A
```

**Solution 2.26.** The triple-loop method performs $n^{3} = 8 \times 10^{6}$ multiply–add operations and its complexity is $O\left( n^{3} \right)$. The @ operator uses optimised BLAS libraries which, through cache-aware blocking, vectorised processor instructions and multithreading, are typically hundreds to thousands of times faster — although their asymptotic complexity is also $O\left( n^{3} \right)$.

**Solution 2.27.** The inner product of two bag-of-words vectors is the sum of the products of the counts of the shared words; so sentences with more words in common appear "more similar". Limitations: it depends on the length of the text (longer texts receive higher scores), it ignores word order and it does not recognise synonymy. Cosine similarity in Chapter 3 fixes the first problem, and word embeddings fix the third.
