## Mathematical exercises

**5.1** Compute the derivative of $f(x) = x^{2}e^{- x}$ and find the points at which $f\prime(x) = 0$.

**5.2** The "softplus" function $s(x) = \log\left( 1 + e^{x} \right)$ is a smooth version of ReLU. Show that $s^{\prime}(x) = \sigma(x)$, where $\sigma$ is the logistic function, and that $s^{\prime\prime}(x) = \sigma(x)\left( 1 - \sigma(x) \right)$. Conclude that $s$ is convex.

**5.3** In $n$ coin tosses, heads came up $k$ times. The log-likelihood is $\ell(p) = k\log p + (n - k)\log(1 - p)$. (a) Compute $\ell^{\prime}(p)$ and find the stationary point. (b) Use the second derivative to show that this point is a maximum.

**5.4** Write down the Taylor polynomials $T_{0},\ldots,T_{3}$ of $f(x) = \ln(1 + x)$ around $x_{0} = 0$ and compare $T_{3}(0.1)$ with $\ln 1.1 \approx 0.09531$.

**5.5** Compute the partial derivatives or gradients of the following functions and state the dimensions of each: (a) $f(x,y) = x^{2}y + e^{xy}$; (b) $f\left( \mathbf{w} \right) = \| \mathbf{w} \|^{2}$ with $\mathbf{w} \in \mathbb{R}^{n}$; (c) $f\left( \mathbf{x} \right) = \mathbf{a}^{\top}\mathbf{x} + b$ with $\mathbf{a} \in \mathbb{R}^{n}$ and $b \in \mathbb{R}$.

**5.6** The logistic loss for a sample $\left( \mathbf{x},y \right)$ with $y \in \{ - 1, + 1\}$ is $L\left( \mathbf{w} \right) = \log\left( 1 + \exp\left( - y\,\mathbf{w}^{\top}\mathbf{x} \right) \right)$. Compute the gradient of $L$ with respect to $\mathbf{w}$ using the chain rule and the intermediate variable $z = y\,\mathbf{w}^{\top}\mathbf{x}$, and show that when the sample is correctly classified with a large margin the gradient is almost zero.

**5.7** Compute the Jacobian of the function $\mathbf{g}:\mathbb{R}^{2} \rightarrow \mathbb{R}^{2}$ with $\mathbf{g}\left( \mathbf{x} \right) = \left\lbrack x_{1}x_{2},\mspace{6mu} x_{1} + x_{2}^{2} \right\rbrack^{\top}$ and its determinant at the point $(1,1)$. What does this number tell us about the map near this point?

**5.8** Compute the gradient of the loss $L\left( \mathbf{x} \right) = \| \mathbf{A}\mathbf{x} - \mathbf{b} \|^{2}$ with respect to $\mathbf{x}$ and derive the normal equations by setting it to zero.

**5.9** Compute the gradient of $f\left( \mathbf{x} \right) = \exp\left( - \frac{1}{2} \| \mathbf{x} - \mathbf{c} \|^{2} \right)$ with respect to $\mathbf{x}$ by introducing the intermediate variable $z = \frac{1}{2} \| \mathbf{x} - \mathbf{c} \|^{2}$. At what point is the gradient zero?

## Conceptual exercises

**5.10** Why does the gradient point in the direction of steepest ascent? Argue using the linear Taylor approximation $f\left( \mathbf{x} + \epsilon\mathbf{d} \right) \approx f\left( \mathbf{x} \right) + \epsilon\nabla f\left( \mathbf{x} \right)\mathbf{d}$ and the Cauchy–Schwarz inequality (Chapter 3).

**5.11** In Figure 5.14, why does the algorithm oscillate in the vertical direction but not in the horizontal direction when the learning rate is large? Relate your answer to the eigenvalues of the Hessian of the function and to the result of Example 5.17.

**5.12** Explain why reverse-mode automatic differentiation is better suited than forward mode for training neural networks. Express your answer in terms of the number of inputs (parameters) and outputs (the loss).

**5.13** Suppose the training of a model has stalled and the gradient is almost zero. How can you tell whether you have reached a minimum or are near a saddle point?

## Programming exercises

**5.14** Write a function that approximates the gradient of an arbitrary function $f:\mathbb{R}^{n} \rightarrow \mathbb{R}$ with central finite differences, and use it to check the gradient of Example 5.16 (gradient checking, Section 5.2). Investigate the effect of the step size $h$ on the accuracy.

```python
import numpy as np
 
def numerical_grad(f, theta, h=1e-5):
    g = np.zeros_like(theta)
    for i in range(theta.size):
        e = np.zeros_like(theta); e[i] = h
        g[i] = (f(theta + e) - f(theta - e)) / (2 * h)   # central difference
    return g
```

**5.15** Run gradient descent on the Rosenbrock function $f(x,y) = (1 - x)^{2} + 100\left( y - x^{2} \right)^{2}$ starting from $( - 1.5,2)$. Plot the path for three learning rates on the contour lines. Why is convergence so slow for this function?

**5.16** Implement logistic regression from scratch using only NumPy: write the cross-entropy loss and its gradient (Example 5.16), train the model with gradient descent on a binary data set, and plot the loss against the iteration number.

## Solutions

**Solution 5.1.** By the product rule: $f\prime(x) = 2xe^{- x} - x^{2}e^{- x} = x(2 - x)e^{- x}$. Since $e^{- x} > 0$, the derivative vanishes only at $x = 0$ and $x = 2$.

**Solution 5.2.** $s^{\prime}(x) = \frac{e^{x}}{1 + e^{x}} = \frac{1}{1 + e^{- x}} = \sigma(x)$. The second derivative is the derivative of $\sigma$: $\sigma^{\prime} = \frac{e^{- x}}{\left( 1 + e^{- x} \right)^{2}} = \sigma(1 - \sigma)$. Since $0 < \sigma < 1$, $s^{\prime\prime} > 0$ and $s$ is convex.

**Solution 5.3.** (a) $\ell^{\prime}(p) = \frac{k}{p} - \frac{n - k}{1 - p}$; setting it to zero gives $k(1 - p) = (n - k)p$, i.e., $\widehat{p} = \frac{k}{n}$. (b) $\ell^{\prime\prime}(p) = - \frac{k}{p^{2}} - \frac{n - k}{(1 - p)^{2}} < 0$; hence $\ell$ is concave and $\widehat{p}$ is a maximum. This is exactly the maximum likelihood estimate of Chapter 8.

**Solution 5.4.** $f(0) = 0$, $f\prime(0) = 1$, $f''(0) = - 1$ and $f^{(3)}(0) = 2$; hence $T_{0} = 0$, $T_{1} = x$, $T_{2} = x - \frac{x^{2}}{2}$ and $T_{3} = x - \frac{x^{2}}{2} + \frac{x^{3}}{3}$. We get $T_{3}(0.1) = 0.1 - 0.005 + 0.000333 \approx 0.09533$, which agrees with $\ln 1.1 \approx 0.09531$ to four decimal places.

**Solution 5.5.** (a) $\partial f/\partial x = 2xy + ye^{xy}$ and $\partial f/\partial y = x^{2} + xe^{xy}$; the gradient is $1 \times 2$. (b) $\nabla_{\mathbf{w}}f = 2\mathbf{w}^{\top}$; dimensions $1 \times n$ (this is the gradient of the ridge regularisation term). (c) $\nabla_{\mathbf{x}}f = \mathbf{a}^{\top}$; dimensions $1 \times n$.

**Solution 5.6.** $L = \log\left( 1 + e^{- z} \right)$ and $\frac{dL}{dz} = - \frac{e^{- z}}{1 + e^{- z}} = - \sigma( - z)$; also $\frac{\partial z}{\partial\mathbf{w}} = y\,\mathbf{x}^{\top}$. Hence $\nabla_{\mathbf{w}}L = - y\,\sigma\left( - y\,\mathbf{w}^{\top}\mathbf{x} \right)\,\mathbf{x}^{\top}$. If the sample is correctly classified with a large margin, $z \gg 0$ and $\sigma( - z) \approx 0$; so such a sample contributes almost nothing to the gradient.

**Solution 5.7.** $\mathbf{J} = \begin{bmatrix} x_{2} & x_{1} \\ 1 & 2x_{2} \end{bmatrix}$, and at $(1,1)$ we have $\det\mathbf{J} = 1 \cdot 2 - 1 \cdot 1 = 1$. So near this point the map approximately preserves area and does not reverse orientation.

**Solution 5.8.** With $\mathbf{e} = \mathbf{A}\mathbf{x} - \mathbf{b}$ we have $\frac{dL}{d\mathbf{x}} = \frac{dL}{d\mathbf{e}}\frac{d\mathbf{e}}{d\mathbf{x}} = 2\mathbf{e}^{\top}\mathbf{A} = 2\left( \mathbf{A}\mathbf{x} - \mathbf{b} \right)^{\top}\mathbf{A}$. Setting it to zero gives $\mathbf{A}^{\top}\mathbf{A}\mathbf{x} = \mathbf{A}^{\top}\mathbf{b}$, i.e., the normal equations (Chapter 9).

**Solution 5.9.** $\frac{df}{dz} = - e^{- z} = - f$ and $\frac{\partial z}{\partial\mathbf{x}} = \left( \mathbf{x} - \mathbf{c} \right)^{\top}$; hence $\nabla_{\mathbf{x}}f = - f\left( \mathbf{x} \right)\,\left( \mathbf{x} - \mathbf{c} \right)^{\top}$. The gradient is zero only at $\mathbf{x} = \mathbf{c}$, which is the maximum of $f$. This function is the RBF kernel of Chapter 12 with $\gamma = \frac{1}{2}$.

**Solution 5.10.** By the first-order Taylor approximation, $f\left( \mathbf{x} + \epsilon\mathbf{d} \right) - f\left( \mathbf{x} \right) \approx \epsilon\nabla f\left( \mathbf{x} \right)\mathbf{d}$. By the Cauchy–Schwarz inequality, over unit vectors $\mathbf{d}$ this inner product is largest when $\mathbf{d}$ points in the same direction as the gradient; hence the gradient is the direction of steepest ascent and its negative is the direction of steepest descent.

**Solution 5.11.** In the problem of Figure 5.14, the curvature of the function — the eigenvalue of the Hessian — is much larger in the vertical direction than in the horizontal one. Gradient descent is stable along a direction only if the learning rate is smaller than $2/\lambda$ for that direction; a rate that suits the low-curvature direction exceeds $2/\lambda_{\max}$ and causes oscillation along the high-curvature direction (Example 5.17).

**Solution 5.12.** In reverse mode, the cost of computing the gradient of a scalar output with respect to all inputs is a small constant multiple of the cost of one function evaluation; forward mode, by contrast, needs a separate pass for each input. When training networks with millions of parameters and a single scalar loss, reverse mode is millions of times cheaper.

**Solution 5.13.** Examine the Hessian at that point: if all its eigenvalues are positive, the point is a local minimum; if there are eigenvalues of different signs, it is a saddle point. For large models, a few of the largest and smallest eigenvalues can be approximated with iterative methods and Hessian–vector products; moreover, adding a little noise and continuing training often moves the algorithm away from a saddle point.

**Solution 5.14.** A sample solution is given in Listing 5.1 and in the book's repository. The error of the central difference is of order $h^{2}$; but a very small $h$ increases the rounding error, so $h$ of about $10^{- 5}$ to $10^{- 6}$ is usually appropriate.

**Solution 5.15.** In the narrow, curved Rosenbrock valley the gradient is almost perpendicular to the axis of the valley; so with a small learning rate convergence is very slow, and with a large one the algorithm oscillates or diverges. This is exactly the ill-conditioning that momentum and Adam in Chapter 7 are designed to cope with.

**Solution 5.16.** The gradient of the cross-entropy loss with respect to the weights is $\frac{1}{N}\sum_{n}^{}\left( \sigma\left( \mathbf{w}^{\top}\mathbf{x}_{n} \right) - y_{n} \right)\mathbf{x}_{n}^{\top}$ (Example 5.16). The complete code and the plot of the decreasing loss are in the book's repository.
