## Mathematical exercises

**9.1** By differentiating $\| \mathbf{y} - \mathbf{\Phi}\mathbf{\theta} \|^{2} + \lambda \| \mathbf{\theta} \|^{2}$ with respect to $\mathbf{\theta}$, derive the closed-form solution of ridge regression and show that the matrix $\mathbf{\Phi}^{\top}\mathbf{\Phi} + \lambda\mathbf{I}$ is invertible for every $\lambda > 0$.

**9.2** For the one-dimensional problem $\min_{\theta}\frac{1}{2}(z - \theta)^{2} + \lambda|\theta|$, show that the solution is "soft thresholding": $\theta^{*} = sign(z)\max\left( |z| - \lambda,0 \right)$. How is this result related to the sparsity of the Lasso?

**9.3** Show that in simple linear regression with an intercept, $R^{2}$ on the training data equals the square of the correlation coefficient between $x$ and $y$ (Chapter 6).

**9.4** Using the results of Section 9.4, prove that the vector of least-squares residuals is orthogonal to all columns of $\mathbf{\Phi}$, and conclude that if one column consists of ones, the residuals sum to zero.

import numpy as np
from sklearn.datasets import load_diabetes
 
X, y = load_diabetes(return_X_y=True)
X = (X - X.mean(0)) / X.std(0); y = y - y.mean()
 
def ridge(X, y, lam):
    D = X.shape[1]
    return np.linalg.solve(X.T @ X + lam * np.eye(D), X.T @ y)

## Solutions

**Solution 9.1.** The derivative of $\| \mathbf{y} - \mathbf{\Phi}\mathbf{\theta} \|^{2} + \lambda \| \mathbf{\theta} \|^{2}$ with respect to $\mathbf{\theta}$ is $- 2\mathbf{\Phi}^{\top}\left( \mathbf{y} - \mathbf{\Phi}\mathbf{\theta} \right) + 2\lambda\mathbf{\theta}$, and setting it to zero gives $\mathbf{\theta}^{*} = \left( \mathbf{\Phi}^{\top}\mathbf{\Phi} + \lambda\mathbf{I} \right)^{- 1}\mathbf{\Phi}^{\top}\mathbf{y}$. For every $\mathbf{v} \neq \mathbf{0}$ we have $\mathbf{v}^{\top}\left( \mathbf{\Phi}^{\top}\mathbf{\Phi} + \lambda\mathbf{I} \right)\mathbf{v} = \| \mathbf{\Phi}\mathbf{v} \|^{2} + \lambda \| \mathbf{v} \|^{2} > 0$; hence this matrix is positive definite and therefore invertible, even if $\mathbf{\Phi}^{\top}\mathbf{\Phi}$ is singular.

**Solution 9.2.** For $\theta > 0$ the derivative is $\theta - z + \lambda$, and setting it to zero gives $\theta = z - \lambda$, which is admissible only if $z > \lambda$; similarly, for $\theta < 0$, $\theta = z + \lambda$ if $z < - \lambda$. If $|z| \leq \lambda$, zero lies in the subgradient $\lbrack - \lambda,\lambda\rbrack + (0 - z)$ and $\theta^{*} = 0$. Hence $\theta^{*} = sign(z)\max\left( |z| - \lambda,0 \right)$. Because every value with $|z| \leq \lambda$ is mapped exactly to zero, the Lasso sets small coefficients exactly to zero and the solution becomes sparse.

**Solution 9.3.** In simple regression the optimal slope is ${\widehat{\theta}}_{1} = r\, s_{y}/s_{x}$, where $r$ is the correlation coefficient. The explained variance is ${\widehat{\theta}}_{1}^{2}s_{x}^{2} = r^{2}s_{y}^{2}$; hence $R^{2} = r^{2}s_{y}^{2}/s_{y}^{2} = r^{2}$.

**Solution 9.4.** From the normal equations, $\mathbf{\Phi}^{\top}\left( \mathbf{y} - \mathbf{\Phi}\mathbf{\theta}_{ML} \right) = \mathbf{0}$; that is, the residual vector is orthogonal to all columns of $\mathbf{\Phi}$. If one column consists entirely of ones, its inner product with the residuals — the sum of the residuals — is zero. In Example 9.4 the residuals are $- 0.05$, $0.15$, $- 0.15$ and $0.05$, which sum to zero.

**Solution 9.5.** The size of each coefficient depends on the unit of the corresponding feature: if floor area is measured in square centimetres instead of square metres, its coefficient becomes ten thousand times smaller without any change in its importance. So coefficients can be compared only after the features have been standardised; and even then, correlated features can share the importance between them.

**Solution 9.6.** The features that are the last to become zero in the Lasso have the most predictive power in the presence of the other features. But this does not imply a causal relationship: if two features are correlated, the Lasso usually keeps one and sets the other to zero; so a feature becoming zero does not necessarily mean that it is unimportant for the disease.

**Solution 9.7.** Adding a column to $\mathbf{\Phi}$ enlarges the column space or leaves it unchanged; so the distance from $\mathbf{y}$ to this space — the residual sum of squares — cannot increase, and the training $R^{2}$ does not decrease. The danger is that the training $R^{2}$ always selects the most complex model; validation data or the adjusted $R^{2}$ should be used instead.

**Solution 9.8.** The confidence interval for the mean prediction contains only the parameter uncertainty, the term $\mathbf{\phi}_{*}^{\top}\mathbf{S}_{N}\mathbf{\phi}_{*}$; the prediction interval for a new observation also adds the noise variance $\sigma^{2}$. Hence the prediction interval is always wider, and with more data it narrows only down to the noise level.

**Solution 9.9.** As $\lambda$ increases, the coefficient path tends smoothly to zero and agrees with the scikit-learn implementation up to rounding error; note that scikit-learn's Ridge does not regularise the intercept. The complete code is in the book's repository.

**Solution 9.10.** Coordinate descent, which repeatedly updates each coefficient by soft thresholding, reaches the same Lasso path as in Figure 9.13(b); for fast convergence, use the solution for the previous $\lambda$ as the starting point (warm start).

**Solution 9.11.** The simple linear model cannot capture the U-shaped relationship and has the largest error; the quadratic model and the degree-day model both have much smaller test errors, and the degree-day model, which uses domain knowledge, is usually more interpretable.
